# IFTM Code 👨‍💻

Organização destinada a reunir códigos-fonte, exemplos, projetos e outros
materiais utilizados em disciplinas que ministro no
**Instituto Federal do Triângulo Mineiro (IFTM) – Campus Uberlândia Centro**.

Os repositórios disponíveis aqui são utilizados como material de apoio às
aulas, demonstrações práticas, exercícios e projetos desenvolvidos com os
estudantes.

## 🎓 Cursos e disciplinas

### Ensino Médio Integrado

Materiais utilizados em disciplinas e Unidades Curriculares Politécnicas,
incluindo:

- Análise de Sistemas
- Introdução à Computação
- Inteligência Artificial Aplicada na Engenharia de Software
- Do Atari ao PS5: Aprendendo Computação com Jogos
- Level Up: Aperfeiçoando o Inglês estudando Análises de Games e Tecnologia no YouTube
- Multifaces do Canva

### Tecnologia em Sistemas para Internet

Materiais relacionados a disciplinas como:

- Algoritmos e Programação
- Lógica de Programação
- Banco de Dados I e II
- Programação Orientada a Objetos
- Engenharia de Software
- Sistemas Operacionais
- Sistemas Distribuídos
- Projeto de Sistemas Web
- Projeto Back-end Monolítico com ORM
- Projeto Back-end: Microsserviços e NoSQL
- Projetos Integradores e Desenvolvimento de Software

### Licenciatura em Computação

Materiais utilizados em disciplinas como:

- Arquitetura de Computadores
- Banco de Dados I e II
- Lógica de Programação
- Sistemas Operacionais

### Pós-graduação

Alguns repositórios também correspondem a materiais utilizados na
Pós-Graduação em Análise e Desenvolvimento de Sistemas Aplicados à
Gestão Empresarial, incluindo conteúdos de:

- Programação Orientada a Objetos
- Desenvolvimento de Sistemas
- Arquiteturas para Desenvolvimento de Sistemas
- Arquitetura Orientada a Serviços e Web Services
- Sistemas para Controle de Versão
- Gestão de Projetos

## 💻 Sobre os repositórios

Os projetos desta organização possuem finalidade predominantemente
**didática**. Por isso, algumas implementações podem priorizar a clareza
e a demonstração de conceitos específicos em vez de representar
arquiteturas completas ou soluções prontas para ambientes de produção.

Cada repositório possui sua própria documentação com informações sobre
a disciplina, tecnologias utilizadas, configuração e execução do projeto.
